# BBL.BOXTV Manager V5

Painel e API V5 para gerenciamento da launcher TV Box.

Inclui dispositivos/clientes, ativação, bloqueio/desbloqueio, vencimento, layouts, biblioteca de APKs, banners, planos de fundo, planos, branding por revenda, notificações, comandos remotos e logs.

A aplicação é iniciada por `main.py`, que exporta o app FastAPI da V5.
